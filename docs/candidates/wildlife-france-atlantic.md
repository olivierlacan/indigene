# Candidate wildlife — Atlantic France

Generated by `npm run wildlife -- --region france-atlantic`. **A shortlist, not a decision** — every row here still needs a human to write the blurb, choose the icon, decide whether the tie is a larval host or a nectar stop, and judge the reliance. See `app/src/data/wildlife.ts`.

GloBI named **19,559** animals on this region's 81 plants. Dropped: 0 not animals, 4 with no iNaturalist match, 42 never recorded inside the region's box, 6 introduced here. What's left is below.

Dropped as introduced, by name, so the guard on `native: true` is visible rather than assumed: _Xylocopa virginica_, _Danaus plexippus_, _Pyrrhocorax graculus_, _Montifringilla nivalis_, _Ovis aries_, _Harmonia axyridis_.

**A native status of `unclear` or `unknown` is not a green light.** iNaturalist records no establishment means at all for the French places, and GBIF's checklists carry stray single "introduced" rows for species that are plainly native — so the veto only fires on unambiguous evidence, and everything short of that is left here for a person to settle.

**Read the interaction type sceptically.** GloBI's `eatenBy` covers a caterpillar stripping a leaf, a finch taking a seed and a deer browsing a twig. Where a record carried a life stage saying "larva" it is called out as **larval evidence**; where it didn't, the tie is "eats it" and the kind of eating is a human's call.
