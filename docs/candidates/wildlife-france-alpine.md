# Candidate wildlife — The French Alps

Generated by `npm run wildlife -- --region france-alpine`. **A shortlist, not a decision** — every row here still needs a human to write the blurb, choose the icon, decide whether the tie is a larval host or a nectar stop, and judge the reliance. See `app/src/data/wildlife.ts`.

GloBI named **18,735** animals on this region's 81 plants. Dropped: 2 not animals, 3 with no iNaturalist match, 43 never recorded inside the region's box, 7 introduced here. What's left is below.

Dropped as introduced, by name, so the guard on `native: true` is visible rather than assumed: _Sturnus vulgaris_, _Streptopelia decaocto_, _Passer domesticus_, _Cygnus olor_, _Anser anser_, _Ovis aries_, _Harmonia axyridis_.

**A native status of `unclear` or `unknown` is not a green light.** iNaturalist records no establishment means at all for the French places, and GBIF's checklists carry stray single "introduced" rows for species that are plainly native — so the veto only fires on unambiguous evidence, and everything short of that is left here for a person to settle.

**Read the interaction type sceptically.** GloBI's `eatenBy` covers a caterpillar stripping a leaf, a finch taking a seed and a deer browsing a twig. Where a record carried a life stage saying "larva" it is called out as **larval evidence**; where it didn't, the tie is "eats it" and the kind of eating is a human's call.
