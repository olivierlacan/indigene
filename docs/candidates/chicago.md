# Candidate plants — Chicago & the Corn Belt Prairie

Generated by `npm run candidates -- --region chicago`. **A shortlist, not a decision** — every row here still needs a human to check that a nursery sells it, and then to write the size curve, the care and gives notes and the basis by hand. See `docs/coverage-plan.md` §2–3.

**Known blind spot:** this ranks by how often a plant is *recorded*, and ecological value is not abundance. The first Pacific Northwest run missed _Ceanothus_ entirely — the one keystone genus `docs/coverage-plan.md` already names as absent from that list — because it is less recorded than bracken. Read this next to `npm run coverage`, never instead of it.

Pool: the 600 most-recorded plant species inside the region's coverage box, out of 1,109,333 georeferenced plant records (GBIF). Native status for Michigan, US, Wisconsin, US, Illinois, US, Iowa, US, Indiana, US, asked of **WCVP** (the World Checklist of Vascular Plants, CC BY, via GBIF) first and of **iNaturalist** only for the names WCVP has no row for. Caterpillar figures are **our own genus-level estimates**, not computed counts — `docs/us-host-counts-plan.md` §2.
