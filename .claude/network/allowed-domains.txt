# Hosts a Claude session working on Indigene needs to reach.
#
# This file is the source. Edit it here, then run `npm run allowlist` (in app/)
# to regenerate the two copies the tools read:
#   .claude/network/paste.txt   paste into a cloud environment's Allowed domains
#   .claude/settings.json       sandbox.network.allowedDomains, for local sessions
# How to apply it: .claude/network/README.md.
#
# One host per line, under the heading that says why we need it. `*.example.org`
# matches every subdomain of example.org, but not example.org itself. A `#`
# starts a comment, on its own line or after a host.
