# Lepidoptera–Plant Associations in Europe

## Description
This repository hosts a comprehensive dataset documenting larval host-plant associations of European Lepidoptera.  
The dataset includes **5,152 Lepidoptera species** and **3,275 vascular plant species**, covering trees, shrubs, and herbaceous plants that occur in Europe as native, naturalized, ornamental, or invasive taxa.  

Data are organized as a **binary interaction matrix**:  
- **Rows** = Lepidoptera species  
- **Columns** = plant species  
- **Values**:  
  - `1` = recorded association  
  - `0` = no record  

Geographic coverage follows the **European Environment Agency boundaries**.  
Records were compiled through an extensive review of published literature, monographs, online repositories, and grey literature. All taxa were standardized following up-to-date classifications for Lepidoptera and vascular plants.  

## Files
- `lep_plant_matrix.csv` – Main interaction matrix (species × species).  
- `README.md` – Dataset description and usage information.  

## Format
- Files are provided in **CSV format** (UTF-8 encoded).  
- Column and row names use standardized scientific names.
