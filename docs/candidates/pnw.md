**Known blind spot:** this ranks by how often a plant is *recorded*, and ecological value is not abundance. The first Pacific Northwest run missed _Ceanothus_ entirely — the one keystone genus `docs/coverage-plan.md` already names as absent from that list — because it is less recorded than bracken.
